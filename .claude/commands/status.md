現在の状態を一覧します。

```bash
python scripts/views.py
```

を実行してから、以下を読んで**表にまとめて**提示してください。

1. **決定** — 本決め何件 / 仮決め何件（`docs/02_decision-log.md`）
2. **仮決めのまま残っている項目** — 全件列挙。放置すると運用テストで突かれる
3. **宿題** — 未消化を全件（担当・期限つき）。期限切れは強調
4. **画面の承認状態** — コード・名前・設計者・状態の一覧（`docs/21_screen-design.md`）
   - **社内レビュー中のまま止まっている新人の画面**があれば強調
   - **未承認なのに詳細仕様が書かれている画面**があれば警告
5. **決定権ステータス**（`docs/04_established-facts.md`）
6. **枠の残り** — 部長への即時確認 ◯/2、管理者への緊急相談 ◯/2
7. **進行中の会議**があればその目的と経過、および残り時間
   ```bash
   python scripts/clock.py
   ```
8. **情報の非対称の監査** — 以下を実行して結果を提示する
   ```bash
   python .claude/hooks/audit.py --report
   ```
   会議中に `client-boss` / `client-staff` を呼んだ回数と、正解ファイルへのアクセス件数が大きく食い違っていたら、`sys-staff` が覗いた疑いがあります。その場合は監督に警告してください

最後に、いま優先して手を打つべきことを1〜3行で述べてください。
