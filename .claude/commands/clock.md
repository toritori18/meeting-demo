```bash
python scripts/clock.py $ARGUMENTS
```

## 時間の数え方

実時間ではなく**シミュレート上の会議時間**です。発言1件ごとに想定所要時間を積み上げます。

| 話者 | 1発言あたり |
|---|---|
| 司会（開会・議題切替・閉会の定型） | 1分 |
| エージェント（質問のまとめ、回答、指摘） | 3分 |
| 監督（あなた）の介入 | 0分（会議時間に含めない） |

**60分の会議 ≒ エージェント18回＋司会4回**。実会議の分量に近く、コストも16〜22回に収まります。

## 残り時間で進行を変える

| 残り | 司会がやること |
|---|---|
| 持ち時間の2/3以上 | 通常進行 |
| 1/3を切った | 終盤。あと1〜2論点。広げない |
| **5分以下** | **着地に入る。新しい議題を開かない。** いま議論中のものだけ片付ける |
| **0以下** | **時間切れ。** 決まったことを記録し、残りは宿題にして `/meeting-close` |

時間切れで全部決まらないのは**正常**です。随時開催なので、次の会議を開けばよい。
無理に延長するより、**何が決まって何が残ったかを明確にして閉じる**ほうが実務に近くなります。

`--detail` で話者別・議題別の内訳が出ます。特定の議題に時間を使いすぎていないかの確認に使ってください。
