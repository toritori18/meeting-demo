---
description: 会議中の監督待ちを畳む／戻す（既定 on）。もう一度実行すると停止モードに戻る
allowed-tools: Bash, Read
---

現在の設定を確認し、切り替えます。

```bash
python scripts/record.py state --key auto
```

- `off` なら `on` にする（**既定**。会議中は監督に判断を戻さない）
- `on` なら `off` にする（会議中も監督の返事を待って止まる）

```bash
python scripts/record.py state --key auto --value on
```

切り替えたら、現在どちらのモードかを明示してください。

## on のとき、司会が監督を待たずに処理すること

| 場面 | 処理 |
|---|---|
| 本日のゴール宣言 | 型の差分から本日外すべきブロックを見て、**閉会後に誰が何に着手できるか**を**司会が判定**し、システム側／業務側の2本立てで宣言してDBに記録する（手順は `/meeting-open` 手順4） |
| 議題ごとの続行可否 | 止まらず次の議題へ |
| 未決の仕分け | **既定は仮決めにして進む**（根拠発言IDを紐づける）。担当と期限が要るものだけ宿題に起票する |
| 決定・宿題の記録 | `/decide` `/todo` の指示を待たず、司会が `record.py` を直接叩く |
| `/escalate` の「待てませんか」 | 確認せず保留に回す（会議の最後に一括で諮る）。**枠は使わない** |

**未決を全部宿題にしないこと。** 宿題だけが増えて何も決まらなくなります。仮決めして進み、次回に本決めへ昇格させます。

## on でも止まる箇所（会議の外側）

| 場面 | 理由 |
|---|---|
| 開会前の**招集案の確認** | 面子を誤ると60分まるごと無駄になる |
| **閉会の起動**（`/meeting-close`） | 残り5分で着地に入り、閉会の準備が整った旨を提示して待つ |
| `/reset` | 破壊的 |

**監督はいつでも平文で割り込めます。** これは on/off に関係ありません。

## 呼び出し回数

持ち時間（既定60分）が上限として効くので、`on` でも**1会議16〜20回**に収まります。
時間制限が無ければ35〜40回に膨らみますが、`clock.py` が残り5分で新しい議題の開始を止めます。
