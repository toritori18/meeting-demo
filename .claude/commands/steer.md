監督からの指示: **$ARGUMENTS**

## 指示が「巻き戻し」「やり直し」の場合

1. 直前のやり取り（監督が指定した範囲）をなかったことにする
2. 該当する発言をDBから削除する
   ```bash
   python scripts/query.py --utterance <直近のID>   # まず確認
   ```
   削除は司会が直接SQLで行う（`utterance` の該当行）。**決定や事実が紐づいている場合は先にそちらを消すこと**
3. 巻き戻した地点から、監督の指定した方針でやり直す

## それ以外の場合

`sys-staff` に方針として渡します。

例:
- 「決定権の確認を先にして」→ 部長がいるうちに委譲確認をさせる
- 「開いた質問をやめて選択肢を出して」→ 新規案件の技法に切り替えさせる
- 「今のは知識の壁だから案を作って当てて」→ 二つの壁の見分けを促す
- 「新人の画面をちゃんとレビューして」→ 社内レビューを促す

指示は司会の発言としてではなく、**監督の介入として記録**します。

```bash
python scripts/log.py --speaker "supervisor" --topic "介入" --body "$ARGUMENTS"
```

渡したあと、`sys-staff` の次の発言が方針を反映しているか確認して提示してください。
