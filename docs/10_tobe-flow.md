## 1. 何をするのか

**受付データ**と、**車検証記録事項の帳票をOCRでデータ化したCSV**を突き合わせ、
食い違いを見つけて直す。

両方とも元をたどれば同じ基幹システムから出ているが、帳票を経由する過程で
人の手や印刷・読み取りが挟まるため、内容が一致しない場合がある。
それを検出するのがこのツールの目的。

## 2. 登場するデータ

| データ | 出どころ | 形式 |
|---|---|---|
| **受付データ** | 別システム（基幹）から出力 | CSV |
| **OCRデータ** | 同じ別システムから出力した**車検証記録事項の帳票**を、OCR製品でデータ化したもの | CSV |
| **出力データ** | このツールが出力し、**別システムに戻す** | CSV |

## 3. 業務の流れ

```
 ┌─ 別システム（基幹）────────────────────────────────────────────┐
 │                                                                │
 │   【1】受付データを出力 ─────────────┐                         │
 │                                      │                         │
 │   【2】車検証記録事項の帳票を出力   ─┼──→ 【3】OCRでCSV化      │
 │                                      │      │                  │
 └──────────────────────────────────────┼──────┼──────────────────┘
                                        ↓      ↓
                           ┌─────────────────────┐
                           │  本ツール           │
                           │  【4】取込          │
                           │  【5】マッチング    │
                           │  【6】データ修正    │
                           │  【7】出力          │
                           └──────────┬──────────┘
                                      ↓
                           【8】別システムに戻す
```

### 各段階

| # | 誰が | 何を |
|---|---|---|
| 【1】 | 業務担当 | 別システムから受付データをCSV出力する |
| 【2】 | 業務担当 | 同システムから車検証記録事項の帳票を出力する |
| 【3】 | 業務担当 | 帳票をOCR製品にかけてCSV化する |
| 【4】 | 業務担当 | **本ツールに【1】と【3】のCSVを取り込む** |
| 【5】 | 本ツール | **受付データとOCRデータを突き合わせる** |
| 【6】 | 業務担当 | **不一致を確認し、直して確定する** |
| 【7】 | 業務担当 | **本ツールから結果を出力する** |
| 【8】 | 業務担当 | 出力したCSVを別システムに戻す |

【1】【2】【3】と【8】は本ツールの範囲外。**【4】〜【7】が今回作るもの。**
